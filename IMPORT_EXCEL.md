# Ручной импорт заявок из Excel

Скрипт `import_leads_from_excel.py` лежит рядом с этой инструкцией, в корне проекта.
Он отправляет заявки через обычный вебхук: запись в PostgreSQL, очередь писем,
затем выгрузка в Google Sheets.

## 1. Загрузить Excel на VPS

На своём компьютере в PowerShell выполни, подставив путь к Excel:

```powershell
scp "C:\Users\jukov\Downloads\export.xlsx" root@45.153.68.72:/opt/WR_wh_leads/logs/imports/export.xlsx
ssh root@45.153.68.72
```

`export.xlsx` — имя для примера. Если используешь другое имя на VPS,
подставь его и в команды ниже. Каталог `logs/imports` на VPS уже создан.

## 2. Проверить файл без загрузки и писем

Дальнейшие команды выполняются на VPS:

```bash
cd /opt/WR_wh_leads
venv/bin/python import_leads_from_excel.py --file logs/imports/export.xlsx
```

Скрипт проверит весь файл и покажет количество строк, уникальных заявок и телефонов.
Без `--send` он ничего не записывает в БД и не отправляет письма.
Если есть ошибка в данных, исправь файл и повтори проверку.

## 3. Запустить импорт

```bash
cd /opt/WR_wh_leads
venv/bin/python import_leads_from_excel.py --file logs/imports/export.xlsx --send
```

Новые заявки попадут в БД и штатную очередь писем. Письма отправляются постепенно,
поэтому завершение скрипта означает завершение загрузки, а не всех отправок.

В выводе `state=new` означает новую заявку, `state=duplicate` — уже существующую.
В конце выводится итог `DONE new=... duplicate=...`.

Повторный запуск с теми же ID не создаёт новые записи и не ставит письма в очередь
повторно. Это относится и к последующей доставке провайдером заявки с тем же ID.
Существующие записи при повторном импорте не обновляются.
Если импорт прервался, можно запустить ту же команду с тем же файлом ещё раз.

## 4. Обновить Google-таблицу

Таблица обновляется автоматически каждые 20 минут. Чтобы обновить сразу:

```bash
cd /opt/WR_wh_leads
/usr/bin/flock -w 45 /tmp/wr_wh_leads_export.lock venv/bin/python export_leads_to_sheet.py
```

Чтобы увидеть окончательные статусы почты, обнови таблицу после завершения очереди
или дождись очередного автоматического обновления.

## 5. Посмотреть отправку писем

```bash
tail -f /opt/WR_wh_leads/logs/email_worker.log
```

`Lead email sent` означает, что SMTP-сервер принял письмо. `Lead email failed`
означает ошибку попытки отправки; штатный воркер выполняет повторы согласно настройкам.
Для выхода из просмотра нажми `Ctrl+C` — отправка продолжится.

## Формат и ограничения

- Поддерживается `.xlsx` с одним листом и заголовками в первой строке.
- Обязательные колонки: `id`, `Domain`, `Phone`, `Created`, `Referer`.
- `Created` — московское время; текстовый формат `2026/10/28 16:38:08`
  или обычная Excel-дата. Для другого часового пояса передай, например,
  `--timezone Asia/Novosibirsk` при проверке и отправке.
- `id` сохраняется как `vid`, по нему работает штатная дедупликация БД.
- `Referer` сохраняется как страница посещения (`page`), параметры URL — в `utm`.
- Строки одного ID объединяются, все телефоны сохраняются в `phones`.
  Письмо и Google-таблица, как и раньше, показывают первый телефон заявки.
- При разных остальных полях у одного ID скрипт останавливается до отправки запросов.
- Используются текущие настройки получателя писем и Google-таблицы из `.env` VPS.
  Перезапуск службы для импорта не нужен.
